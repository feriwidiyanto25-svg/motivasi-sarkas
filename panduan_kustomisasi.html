🚀 Mengubah Mode Menjadi Auto Upload YouTube

Saat ini sistem berada di Mode Review Manual (video dikirim ke Telegram, lalu Anda klik tombol Upload YouTube). Anda dapat mengaktifkan Mode Full Autopilot agar video otomatis di-upload ke YouTube setelah render selesai.

Opsi A: Melalui File config.py (Lokal & Runner)

Buka file config.py pada baris 46, ubah nilai default menjadi "true":

# config.py - Baris 46
AUTO_UPLOAD_YOUTUBE = os.environ.get("AUTO_UPLOAD_YOUTUBE", "true").lower() == "true"

Opsi B: Melalui GitHub Repository Secrets / Vars

Tanpa mengubah kode python, tambahkan variabel di GitHub Actions:

  1. Masuk ke GitHub repo -> Settings -> Secrets and variables -> Actions.
  2. Pilih tab Variables -> Klik New repository variable.
  3. Name: AUTO_UPLOAD_YOUTUBE | Value: true.

📋 Syarat Wajib Auto Upload Berhasil:

  • GitHub Secret YOUTUBE_CREDENTIALS_JSON sudah diisi OAuth client credentials dari Google Cloud Console.
  • GitHub Secret YOUTUBE_TOKEN_JSON sudah berisi access token + refresh token YouTube channel Anda.
  • Workflow akan otomatis mengunggah video, memasang custom thumbnail, dan mengirim notifikasi link video YouTube ke Telegram Anda.

🎨 Mengubah Ukuran Teks, Warna, dan Ketebalan Efek

Seluruh pengaturan visual teks diatur di dalam file video_engine.py.

1. Mengubah Ukuran Huruf (Font Size)

Buka video_engine.py pada baris 53 - 55:

# video_engine.py (Baris 53-55)
TEXT_WIDTH = 640 # Lebar area teks (Layar: 720px, margin kiri/kanan 40px)
TITLE_FONT_SIZE = 38 # Ukuran huruf Judul Utama (Rekomendasi: 36 - 42)
SCENE_FONT_SIZE = 44 # Ukuran huruf Subtitle Berjalan (Rekomendasi: 42 - 50)

💡 Tips: Jika ingin subtitle lebih raksasa dan memenuhi tengah layar, ubah SCENE_FONT_SIZE = 48.

2. Mengubah Warna Teks & Badge

Buka fungsi generate_layout_elements() di video_engine.py:

A. Badge "KENAPA YA?" (Pill Atas)
# Ganti warna background badge:
badge_bg = ColorClip(
  size=(190, 42),
  color=(250, 204, 21) # Kuning (#FACC15)
)

# Pilihan warna alternatif:
- Merah: (239, 68, 68)
- Putih: (255, 255, 255)
- Cyan: (6, 182, 212)
B. Warna Huruf Judul & Subtitle
# Judul Utama (Baris ~228):
title_shadow, title_main = create_styled_text_pair(
  title_text,
  fontsize=TITLE_FONT_SIZE,
  color="white", # Ganti "#FACC15" untuk Judul Kuning
  ...
)

# Subtitle Kalimat (Baris ~252):
color="white", # Putih solid kontras tinggi

3. Mengatur Ketebalan Garis Tepi & Bayangan (Shadow)

Pada pemanggilan create_styled_text_pair(...):

stroke_color="black",
stroke_width=1.5, # 1.0 = halus, 1.5 = ideal, jangan > 3 agar huruf tidak tersumbat
shadow_offset=(3, 4) # Geser bayangan hitam (X: +3px ke kanan, Y: +4px ke bawah)

📐 Mengatur Koordinat Posisi Elemen (Sumbu Y)

Layar vertikal YouTube Shorts memiliki tinggi 1280 piksel. Berikut adalah peta pembagian koordinat vertikal yang optimal:

Y: 0 – 200 (Area Bahaya Header YouTube)
KENAPA YA? (Y: 260)
JUDUL PERMANEN (Y: 318)
SUBTITLE BERJALAN
(OPTICAL CENTER Y: 620)
Y: 960 – 1280 (Area Bahaya UI YouTube: Judul, Subscribe, Tombol Like/Komentar)

Cara Memindahkan Posisi di Kode:

1. Menaikkan/Menurunkan Header (Badge + Judul):

Ubah variabel BADGE_Y = 260 di video_engine.py.
Judul otomatis mengikuti di bawah badge secara rapat (TITLE_Y = BADGE_Y + 42 + 16).

2. Menaikkan/Menurunkan Subtitle Berjalan:

Ubah variabel OPTICAL_CENTER_Y = 620 di video_engine.py.
• Jika ingin agak naik sedikit: ganti ke 580.
• Jika ingin agak turun mendekati batas aman: ganti ke 660.

🎙️ Kustomisasi Karakter Suara AI (TTS) & Musik Latar (BGM)

Pengaturan audio diatur dalam file config.py pada baris 33 - 39:

A. Memilih Karakter Suara (Edge-TTS)

# Pilihan 1: Suara Wanita (Ramah, Jernih)
TTS_VOICE = "id-ID-GadisNeural"

# Pilihan 2: Suara Pria (Berwibawa, Edukasi)
TTS_VOICE = "id-ID-ArdiNeural"

Keduanya adalah model neural Microsoft paling natural untuk Bahasa Indonesia tanpa perlu API Key berbayar.

B. Kecepatan & Volume Mixing

TTS_RATE = "+0%" # Atur "+5%" atau "+10%" jika ingin lebih cepat
VOICEOVER_VOLUME = 1.0 # 100% volume narator
BGM_VOLUME = 0.15 # 15% volume musik latar

BGM diambil secara acak dari folder assets/audio/setup/. Anda bisa memasukkan lagu MP3 baru ke folder tersebut kapan saja.

⚠️ Solusi Error: HTTP 401 Bad Credentials saat Upload YouTube

Pesan error HTTP 401 { "message": "Bad credentials", "documentation_url": "https://docs.github.com/rest" } terjadi ketika token GitHub Personal Access Token (PAT) di Cloudflare Worker Anda telah kedaluwarsa atau tidak valid.

Langkah 1: Generate Token Baru di GitHub
  1. Buka tautan: github.com/settings/tokens.
  2. Pilih Generate new token (classic).
  3. Isi Note: Telegram Bot Uploader.
  4. Pilih Expiration: No expiration (agar tidak expired lagi di masa depan).
  5. Centang hak akses: repo (Full control of private repositories) dan workflow.
  6. Klik tombol Generate token di paling bawah dan salin token ghp_... Anda.
Langkah 2: Perbarui Token di Cloudflare Worker
  1. Buka dashboard Cloudflare -> Workers & Pages.
  2. Pilih Worker Bot Telegram Anda.
  3. Masuk ke menu Settings -> Variables and Secrets.
  4. Edit variabel GITHUB_TOKEN (atau GH_PAT), paste token baru ghp_..., lalu klik Save and Deploy.
